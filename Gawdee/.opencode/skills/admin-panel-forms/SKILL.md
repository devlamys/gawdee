# Admin Panel Forms & Settings

## Directives
- Build robust control panels in `admin/page.tsx` with controlled checkbox, toggle, and input fields.
- Integrate with `admin-api.ts` to manage loading, dirty form indicators, and error banners.
- Handle optimistic UI updates on toggles, falling back to server state on API errors.
- Group related configuration keys logically with clear labels and help text.
