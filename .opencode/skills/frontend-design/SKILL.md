# Frontend Design & UI/UX Expert

## Directives
- Implement pixel-faithful layouts matching designs precisely.
- Maintain consistent visual hierarchy: clear section kickers, bold editorial headers, clean metadata, and legible pricing tags.
- Enforce standard spacing tokens (4px/8px grid scale).
- Ensure high-contrast CTA buttons, smooth micro-interactions, and responsive behavior (mobile-first, tablet, desktop).
